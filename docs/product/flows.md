# 사용자 흐름

개인 갤러리는 부부가 직접 시작하고, 스튜디오 갤러리는 작가가 사진을 올린 뒤 고객을 초대한다.

## 개인 사용자

1. 로그인하고 무료 또는 Pro 이용권으로 갤러리를 만든다.
2. 사진·ZIP을 업로드하고 AI가 만든 컨셉·세부 폴더를 정리한다.
3. 셀렉에서 사진을 고르고 별점을 매긴다. 선택 여부·여러 별점·별점 없음·지인 좋아요·AI 추천 조건을 조합해 거를 수 있다.
4. 원하는 사진을 공유폴더에 담아 지인 반응을 받는다. 현재 보는 사진이나 별점 조건으로도 공유폴더를 만들 수 있다.
5. 선택 사진의 보정 내용을 작성하고 PDF 요청서를 내려받아 업체에 전달한다.
6. 보정본을 올려 확인하고 작업을 마무리한다.

상단 단계 메뉴로 업로드·폴더 정리·셀렉을 오간다. 폴더 정리로 돌아가도 선택·별점·보정 작성 내용을 유지한다. 요청서 내보내기 뒤에는 **보정본이 오기 전이고 서버의 취소 조건을 만족할 때** 다시 선택할 수 있다. 이미 업체에 보낸 PDF는 자동 수정되지 않으므로 새 요청서를 다시 전달해야 한다.

근거 : [단계 이동 #155](https://github.com/organic-agent/organic-agent-web/pull/155), [내보내기 취소 #139](https://github.com/organic-agent/organic-agent-web/pull/139), [필터·공유 #154](https://github.com/organic-agent/organic-agent-web/pull/154).

## 스튜디오와 초대받은 부부

| 주체 | 흐름 |
|:---|:---|
| 작가·구성원 | 작업공간 선택 → 갤러리 생성 → 사진 업로드·폴더 정리 → 고객 초대 → 선택·요청 확인 → 보정본 업로드·처리 |
| 초대받은 부부 | 초대 수락 → 폴더 탐색 → 공동 셀렉·별점·지인 공유 → 선택 제출·보정 작성 → 결과 확인 |
| 지인·게스트 | 공유 링크 → 닉네임·신원 확인 → 공유 사진 확인 → 좋아요·댓글 |
| 최고 관리자 | Tailnet → 별도 로그인 → 이용권·계정·갤러리·처리 실패 운영 |

개인 갤러리의 취소·단계 이동 규칙을 스튜디오 갤러리의 권한으로 확대하지 않는다. 공개 상태·업무 상태·화면 단계도 서로 다른 값이다. [현재 구현과 남은 작업](../implementation-status.md)

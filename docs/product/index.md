# 제품

EasySelect는 사진작가 또는 스튜디오가 웨딩 사진 갤러리를 만들고 촬영 사진을 업로드하면, AI가 사진의 시각적 유사도와 기술 품질을 분석하여 유사 사진 스택을 구성하고, 부부가 **직접 셀렉 · AI 1차 셀렉 · 게스트 협업**을 활용해 최종 사진을 선택하여 사진작가에게 전달하는 **사진 셀렉 플랫폼**입니다.

현재 범위에는 사진 업로드와 탐색, 폴더 구성, 직접·AI·협업 셀렉, 최종 제출, 웹 앨범 목업과 AI 보조 보정 요청이 포함됩니다. 실물 앨범 제작, 인쇄용 파일 생성, 결제와 배송은 포함하지 않습니다.

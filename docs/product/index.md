# 제품

EasySelect는 수천 장의 촬영 사진을 폴더로 정리하고, 부부가 선택·공유·보정 요청을 이어 가는 웨딩 사진 셀렉 서비스다. 스튜디오가 개설한 갤러리와 부부가 직접 개설하는 개인 갤러리를 제공한다.

## 한 번의 사용 흐름

**사진 업로드 → AI 컨셉·세부 폴더 → 셀렉·별점·지인 반응 → 보정 작성·요청서 전달 → 보정본 확인**

AI는 정리와 추천을 보조한다. 사진을 최종 선택하거나 요청서를 확정하는 주체는 사용자다. 현재 웹은 폴더 정리와 셀렉 사이를 오갈 수 있고, 개인 갤러리에서는 보정본이 오기 전 요청서 내보내기를 취소할 수 있다.

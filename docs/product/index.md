# 제품

EasySelect는 여러 작업공간에서 갤러리를 운영하고, 고객과 게스트가 사진을 선택하며, 스튜디오가 보정 결과를 납품하는 웨딩 사진 워크플로다.

현재 범위는 작업공간·구성원, 갤러리·사진, AI 보조 카테고리, 셀렉·별점, 사용자·게스트 협업, 보정 요청·결과, 알림과 관리자 운영이다. 앨범·목업은 명시적으로 삭제했다.

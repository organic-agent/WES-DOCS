# 기능별 정책

이 페이지는 현재 `main`의 공통 규칙을 정리한다. 화면 동작과 개발 중인 변경은 [구현 상태](../implementation-status.md)에서 구분한다.

## 개인 이용권과 쿠폰

| 플랜 | 사진 수 | 이용 기간 | 개설 조건 |
|:---|---:|:---|:---|
| 무료 | 500장 | 갤러리 생성일부터 달력 기준 1개월 | 계정당 1회 |
| Pro | 10,000장 | 갤러리 생성일부터 달력 기준 1년 | 유효한 Pro 쿠폰 |

쿠폰은 `SINGLE_USE`(1회용), `ONCE_PER_ACCOUNT`(공유·계정당 1회), `UNLIMITED`(반복 사용)를 지원한다. **쿠폰 사용 마감과 갤러리 이용 만료는 별개**다. 등록한 쿠폰도 실제 갤러리를 만들 때 마감을 다시 검사한다. 공유 코드 비활성화는 이후 사용을 막으며 이미 만든 갤러리를 취소하지 않는다. 카드 결제·환불은 아직 서비스 범위에 넣지 않는다.

근거 : [서버 #327](https://github.com/organic-agent/organic-agent-server/pull/327), [웹 #151](https://github.com/organic-agent/organic-agent-web/pull/151), [이용권 모델](../data-model/billing.md).

## 사진과 폴더

- 사진은 S3로 직접 전송한다. 웹은 큰 JPEG를 2,048px로 줄일 수 있으며, PNG·WebP·HEIC 등은 업로드 경로의 형식·크기 검사를 따른다. RAW 지원을 보장하지 않는다.
- AI 결과는 `컨셉 → 세부 폴더 → 사진 배정`으로 반영한다. 세부 폴더 이동·병합·이름 변경과 수동 정리를 제공한다.
- 현재 공유폴더는 사진 ID 목록을 따로 보관한다. 컨셉·세부 폴더를 옮기거나 지워도 공유 범위와 반응을 자동으로 없애지 않는다.

## 셀렉과 반응

- 갤러리당 하나의 공동 셀렉을 사용한다. 사진과 선택 순서는 중복하지 않는다.
- 별점은 사진당 공동 값 하나이며 마지막 작업자가 기록된다. 개인별 별점 분리는 제안 상태다.
- 선택 제출·내보내기는 편집을 잠근다. 개인 내보내기 취소와 스튜디오 제출 철회는 다른 조건·권한을 사용한다.
- 변경 번호 조회 API가 선택·별점 동기화를 지원한다. 현재 웹의 자동 반영 주기를 API 목표만으로 단정하지 않는다.
- 공유 참여자는 `USER/GUEST`로 구분하고, 허용된 사진에만 좋아요·댓글을 남긴다.

## 보정·삭제·운영

보정은 고객의 요청 작성과 결과 파일 처리를 구분한다. 개인 갤러리도 결과 업로드 경로를 제공하며 스튜디오 권한과 동일하게 취급하지 않는다. 요청서 내보내기 취소는 보정본 업로드 이후 사용할 수 없다.

실제 사진 삭제는 휴지통·복원·영구 정리 흐름을 사용한다. 개발 중인 **셀렉 제외 폴더**는 원본 삭제와 별도 기능이며 아직 현재 제품에 포함하지 않는다. 사용자 알림 저장과 이메일·브라우저 외부 발송도 구분한다.

관리자는 Tailnet과 별도 세션을 거쳐 운영한다. 현재 main의 감사·사유·리비전과 develop의 제거 작업은 [백오피스](../tech/backoffice.md)에 구분한다.

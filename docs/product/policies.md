# 기능별 정책

기획서 §4~§10에서 확정된 정책을 기능별로 정리했습니다. 숫자로 확정된 정책은 표로 먼저 보여줍니다.

## 숫자로 확정된 정책

| 정책 | 값 |
|:---|:---|
| OAuth 제공자 | 카카오 · 구글 · 네이버 3사 |
| 갤러리당 부부 인원 | 정확히 2명 (공동 계정 없음) |
| 부부 초대 링크 만료 | 7일 (재발급 시 기존 링크 폐기) |
| 협업 공유 URL·토큰 만료 | 7일 (부부가 언제든 폐기 가능) |
| 유사도 슬라이더 | 5틱, 기본값은 가장 왼쪽 "스택 없음" |
| 폴더 계층 | 부모 폴더 → 자식 폴더 → 이미지 3단계 고정 |
| AI 셀렉 동시 실행 | 갤러리당 1작업 |
| 지원 사진 형식 | jpg · jpeg · png · raw · heic |

## 인증, 초대와 작업공간

- 랜딩에서 첫 가입 → 사진작가, 갤러리 초대 링크에서 가입 → 부부로 역할이 정해집니다.
- 초대 링크는 작가가 발급·복사해 **직접 전달**합니다 (자동 발송 없음).
- 부부 초대 수락에 작가의 재승인 단계는 없습니다.

## 갤러리와 사진 업로드

- 업로드 실패 시 자동 재업로드를 시도하고, 복구가 안 되면 같은 사진을 다시 올릴 수 있습니다. 최종 실패는 사용자에게 알립니다.
- RAW·HEIC는 고화질 표시용 변환본을 별도로 만들고, **다운로드는 항상 원본**입니다.
- AI는 시각적 유사도와 셀렉 순위용 기술 품질 신호를 계산할 뿐, 컨셉 카테고리를 만들거나 정상 사진을 임의로 폐기하지 않습니다.

## 사진 탐색과 폴더

- 탐색 수단은 사진 그리드(전체·선택 상태 확인) · 싱글뷰(연속 열람) · 비교 셀렉(나란히 비교) 세 가지입니다.
- 유사도 슬라이더는 왼쪽으로 갈수록 한 스택의 사진 수가 적어지고, 스택은 포함 장수 순으로 정렬합니다.
- 슬라이더로 만든 스택 구성은 폴더 구조로 **고정**해 저장합니다. 사진 이동은 같은 부모 아래 자식 폴더 사이에서만 허용합니다.

## 직접 셀렉, 조기 마감과 제출

- 현재 선택 장수와 목표 장수를 함께 표시합니다. **목표보다 적게 선택한 상태는 차단하지 않고**, 목표에 도달하면 추가만 차단합니다.
- 마감 후 부부는 수정할 수 없지만 **작가는 마감 후에도 수정할 수 있습니다.**
- 부부의 두 계정은 같은 선택 결과를 공동 편집합니다 (동시 편집 충돌 처리는 미정).
- 조기 마감은 일반 마감과 동일하게 선택을 잠그며 **되돌릴 수 없습니다.**
- 제출 시 작가에게 선택 완료 알림이 전달됩니다 — 현재 정의된 유일한 외부 자동 알림(`SelectionSubmitted`)입니다.
- 제출 후에도 결과를 다시 열 수 있지만 편집은 불가합니다.

## 협업 셀렉, 좋아요와 댓글

- 부부가 협업 폴더에 사진을 담고 최상위 폴더 단위로 링크를 발급합니다.
- 게스트는 접속 시 닉네임을 설정하고, 협업 폴더에 포함된 사진만 볼 수 있습니다.
- 게스트의 좋아요·댓글은 같은 폴더의 다른 게스트에게도 보입니다. 조회·삭제 권한은 부부와 작성자 본인에게 있습니다.

## 앨범 템플릿과 목업

- 템플릿은 스튜디오 단위 자산으로 여러 갤러리에 재사용하고, 레이아웃 수정 권한은 스튜디오에만 있습니다.
- 부부는 사진 순서와 프레임 안의 크롭 영역만 수정합니다. 프레임 위치·크기·개수와 펼침면 구성은 읽기 전용입니다.
- 목업은 구성과 배치를 이해하기 위한 웹 미리보기이며, 실물 재질·두께·인쇄 색상을 보증하는 3D 시뮬레이션이 아닙니다.

## AI 보조 보정 요청

1. 작가가 가능한/불가능한 보정 방식을 미리 등록
2. 부부가 자연어 요청 + 사진 위 표시 입력
3. AI가 모호한 표현을 전처리하고 작가의 처리 범위에 맞춰 초안 정리
4. 부부가 정리된 요청을 확인하고 동의
5. 작가가 합의된 보정 요청 수신

{: .note }
확정되지 않은 정책들(동시 편집 충돌, 파일 크기 제한, 갤러리당 최대 장수 등)은 [미정과 범위 밖](scope.md)에 모아 두었습니다.

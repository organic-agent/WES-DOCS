# 주요 개념과 역할

제품을 이루는 8개 핵심 개념이다. 세부 정책은 [기능별 정책](policies.md)에 있다.

## 계정과 역할

계정은 실제 사용자를 나타내는 로그인 단위다. **어디서 가입했는지가 역할을 결정한다** — 랜딩 페이지에서 처음 가입하면 `PHOTOGRAPHER`(사진작가), 갤러리 초대 링크에서 가입하면 `CLIENT`(부부)다. 부부는 공동 계정을 쓰지 않고 각자 자신의 계정으로 같은 갤러리에 참여한다.

접근 범위는 인증 여부만이 아니라 역할, 스튜디오 소속, 갤러리 초대 링크와 협업 공유 링크를 함께 검사해 결정한다.

---

## 사진작가 / 스튜디오 작업공간

사진작가와 스튜디오 운영자는 하나의 역할로 취급한다. 스튜디오는 갤러리와 구성원을 관리하는 작업공간이고, 개인 사진작가도 별도 작업공간을 만들 수 있다. 현재 소유 정책은 **1작가 = 1스튜디오**이며, 한 스튜디오에 여러 작가가 참여하는 방식은 추후 논의 대상이다.

---

## 갤러리

특정 촬영 건의 사진, 선택 마감일, 목표 선택 장수, 참여자를 관리하는 작업 단위다.

{: .note }
갤러리에는 서로 **독립적인 두 개의 상태 축**이 있다. 업무 상태(`생성 → 진행 → 완료 → 보관`)와 공개 상태(`Draft / Open / Close`)는 별개이고, 선택 마감일과도 별개의 값이다.

---

## 폴더와 유사 사진 스택

AI 분석 결과인 유사 사진 묶음(스택)을 사용자가 **고정하면 폴더가 된다**. 고정된 구조는 `부모 폴더 → 자식 폴더 → 이미지`의 3단계만 허용하고, 실제 이미지는 자식 폴더에 속한다. 사진 이동은 같은 부모 폴더 아래의 자식 폴더 사이에서만 허용한다.

---

## AI 1차 셀렉

부부가 선택 앨범에서 실행하는 **수정 가능한 선택 초안**이다. 기존 수동 선택을 유지한 채 목표 선택 장수까지 남은 사진을 채우며, 기준은 기술 품질 · 유사 사진 중복 제거 · 촬영 흐름의 다양성이다. AI는 개인 취향을 학습하지 않고, 초안을 자동 확정하거나 사진작가에게 제출하지 않는다. 부부가 초안을 추가·해제·교체한 뒤 기존 제출 흐름으로 확정한다.

---

## 협업 셀렉

부부가 선택한 일부 사진을 별도 협업 폴더로 구성해 게스트의 좋아요와 댓글을 받는 기능이다. 협업 폴더는 일반 폴더와 같은 구조를 쓰고, 공유 단위는 최상위 폴더다. 링크 발급 시 공유 URL과 별도 접속 토큰을 생성한다.

---

## 앨범 템플릿과 목업

앨범 템플릿은 스튜디오가 반복 사용할 웹 목업의 배치 규칙으로, 앨범 규격 · 표지 · 2D 펼침면 · 페이지 구성과 사진 프레임의 위치·크기·비율을 포함한다. 앨범 목업은 선택 사진이 템플릿에 반영된 웹 미리보기다. 부부는 **사진 순서와 프레임 안의 크롭 영역만** 수정할 수 있고, 레이아웃은 읽기 전용이다.

---

## 보정 요청

부부가 모호한 자연어 요청과 사진 위 표시로 보정 내용을 입력하면 **AI가 전처리해 규격화된 요청 초안**을 만든다. 사진작가는 가능한/불가능한 보정 방식을 미리 등록하고, 부부가 정리된 내용에 동의한 뒤 요청이 전달된다. AI가 보정을 직접 수행하는 기능이 아니라, 고객과 사진작가 사이의 요청을 구조화하고 합의를 돕는 기능이다.

> 목적은 모호한 요구를 사전에 합의 가능한 형태로 정리하여 컴플레인을 줄이고 사진작가의 처리 편의를 높이는 것이다.
> — 제품 기획서 §2

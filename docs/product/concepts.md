# 주요 개념과 역할

계정은 로그인 신원이고, 작업공간은 소유·운영 범위이며, 갤러리는 한 촬영 건의 사진 작업 단위다.

| 개념 | 의미 |
|:---|:---|
| PERSONAL 작업공간 | 개인 사용자가 소유한다. 무료·Pro 이용권으로 갤러리를 만들고 파트너를 초대한다. |
| STUDIO 작업공간 | 작가와 구성원이 갤러리를 운영한다. OWNER/MEMBER 관계로 권한을 계산한다. |
| 갤러리 | 사진·목표 장수·선택 마감·이용 기간·진행 단계를 묶는다. |
| 컨셉·세부 폴더 | 사진을 정리하는 2층 구조다. 사진은 세부 폴더 하나에 배정되거나 미분류로 남는다. |
| 연사·임베딩 그룹 | AI 내부의 유사 사진 묶음이다. 사용자 폴더나 공유폴더와 동일하지 않다. |
| 공동 셀렉 | 갤러리당 하나의 선택 결과다. 현재 별점도 사진당 공동 값 하나를 사용한다. |
| 공유폴더 | 지인에게 보여 줄 사진 ID를 따로 담는 공유 단위다. 원래 폴더 이동과 독립적이다. |
| 보정 요청서 | 선택 사진의 요청 문구·표시를 정리한 전달물이다. 웹은 PDF 내보내기를 제공한다. |
| 사진 라벨 | 눈 감음·구도처럼 겹쳐 붙는 속성이다. 현재는 개발 중이며 폴더를 대체하지 않는다. |

최종 STUDIO OWNER는 제거할 수 없다. 개인 파트너와 스튜디오 고객의 권한은 초대 종류·작업공간·갤러리 관계로 판단한다. 세부 정책은 [기능별 정책](policies.md), 어휘의 정본은 [용어집](../glossary.md)을 따른다.

# 미정과 범위 밖

현재 구현 계약과 앞으로 결정할 문제를 구분한다.

## 추후 결정

| 영역 | 항목 |
|:---|:---|
| 셀렉 | 동시 편집 충돌 UX와 제출 철회 정책의 제품 노출 |
| 보정 | 추가 보정 회차와 고객 승인 단계의 상세 규칙 |
| 업로드 | 형식별 최대 파일 크기와 갤러리별 처리 한도 |
| 알림 | 이메일·브라우저 채널의 실제 발송 정책 |
| 운영 | 리소스별 복원 창과 영구 삭제 SLA |
| 사업 | 가격, 과금 주체와 제품 성공 지표 |

## 현재 범위 밖

| 분류 | 하지 않는 것 |
|:---|:---|
| 앨범 | 앨범 폴더·템플릿·목업·배치·인쇄·배송 |
| 결제 | 결제, 환불과 스튜디오 정산 |
| AI | 제품 서버 안에서 모델 실행 |
| AI | AI 초안 자동 제출과 최종 판단 대체 |
| 편집 | Lightroom·Photoshop 같은 원본 보정 도구 대체 |
| 인프라 | 관리자 API의 공개 인터넷 노출과 Tailscale Funnel |

{: .note }
과거 스프린트와 인터뷰에 앨범·클러스터가 등장하지만 현재 기능이 아니다. [ADR-009](../decisions/adr-009-gallery-category-model.md)와 [ADR-012](../decisions/adr-012-remove-album-feature.md)가 대체 결정을 기록한다.

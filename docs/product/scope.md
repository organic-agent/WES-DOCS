# 미정과 범위 밖

회의에서 논의한 개선과 실제 배포 계약을 구분한다.

## 진행·검토 중

| 항목 | 2026-11-04 상태 |
|:---|:---|
| 선택·별점 동기화 | 서버 변경 번호·마지막 작업자 API는 main 반영. 웹의 연결은 별도 확인 대상. |
| 셀렉 휴지통 | 서버 PR #365·웹 이슈 #160 진행 중. 원본 삭제 없이 제외·복원하는 기능. |

| 추천에 거절·별점 반영 | 회의 제안. 현재 분석 모델이 사용자 별점을 읽는 것으로 설명하지 않는다. |
| 관리자 단순화 | develop에 감사·사유·변경 복원 제거 반영. 현재 main과 구분. |

근거와 링크는 [구현 상태](../implementation-status.md)에 모은다.

## 현재 범위 밖

카드 결제·환불·스튜디오 정산, 실물 앨범 인쇄·배송, 전문 이미지 보정 도구 대체, AI의 자동 최종 제출, 관리자 API 공개 노출은 포함하지 않는다. 이메일·브라우저 실제 발송과 서비스 수준 보장은 별도 결정이 필요하다.

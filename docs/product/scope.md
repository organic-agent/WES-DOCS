# 미정과 범위 밖

{: .note }
2026-09-05 확정 정책과 Server V6 기준이다. 현재 Web에는 이전 계약·로컬 상태가 남아 있으므로 화면 연동 완료 여부는 [구현 기준과 확인 상태](../implementation-status.md)와 [프론트엔드](../tech/web.md)를 따로 확인한다.

현재 구현 계약과 앞으로 결정할 문제를 구분한다.

## 추후 결정

| 영역 | 항목 |
|:---|:---|
| 셀렉 | 공동 편집 충돌·서버 제출 철회 권한을 Web에 노출하는 UX |
| 보정 | 추가 보정 회차와 고객 승인 단계의 상세 규칙 |
| 업로드 | 형식별 최대 파일 크기와 갤러리별 처리 한도 |
| 알림 | 이메일·브라우저 채널의 실제 발송 정책 |
| 운영 | 기본 7일 복원 이후 purge 실행 지연·재시도에 대한 SLA |
| 사업 | 가격, 과금 주체와 제품 성공 지표 |

## 현재 범위 밖

| 분류 | 하지 않는 것 |
|:---|:---|
| 결제 | 결제, 환불과 스튜디오 정산 |
| AI | 제품 서버 안에서 모델 실행 |
| AI | AI 초안 자동 제출과 최종 판단 대체 |
| 편집 | Lightroom·Photoshop 같은 원본 보정 도구 대체 |
| 인프라 | 관리자 API의 공개 인터넷 노출과 Tailscale Funnel |

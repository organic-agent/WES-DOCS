# 미정과 범위 밖

무엇을 만들지만큼 **무엇을 아직 정하지 않았고, 무엇을 하지 않기로 했는지**를 명시적으로 관리한다. 미정 항목은 결정을 미룬 것이고, 범위 밖 항목은 의도적으로 하지 않는 것이다.

## 현재 미정 또는 추후 논의 (16)

| 영역 | 미정 항목 |
|:---|:---|
| 작업공간 | 한 스튜디오에 여러 사진작가가 참여하는 구성원 정책 |
| 작업공간 | 복수 스튜디오 소속의 상세 운영 규칙과 가입 시 역할 선택 절차 |
| 셀렉 | **부부 두 계정의 동시 편집 충돌 처리** |
| 제출 | 제출 결과의 재제출·확정 취소 상태 |
| 제출 | 마감일 경과와 제출 결과 다시 열기 사이의 우선순위 |
| 보정 | 1차 보정 사진을 교체하여 2차 보정을 요청하는 기능의 필요성과 규칙 |
| 보정 | 보정 완료 사진을 별도 도메인으로 관리할지 여부 |
| 업로드 | 업로드 실패·중복·처리 상태의 상세 UI |
| 업로드 | 형식별 검증, 파일 크기, 갤러리별 최대 사진 수와 처리 인프라 규모 |
| 앨범 | 지원할 앨범 규격·펼침면 수·프레임 수와 레이아웃 제한 |
| 앨범 | 프레임 수와 목표 선택 장수가 다를 때의 처리 |
| 앨범 | 셀렉 중 템플릿 수정 시 기존 목업에 적용할 버전 정책 |
| 앨범 | 크롭 원본 비율, 최소 해상도 경고와 편집값 저장 정책 |
| 앨범 | 목업과 실제 인쇄 결과의 차이를 안내하는 방식 |
| 운영 | 갤러리 휴지통과 영구 삭제 정책 |
| 사업 | **가격 정책, 운영자 기능과 제품 성공 지표** |

## 현재 범위 밖인 기능 (13)

| 분류 | 하지 않는 것 |
|:---|:---|
| 실물 제작 | 실물 앨범 재질·두께·인쇄 색상의 3D 시뮬레이션 |
| 실물 제작 | 인쇄용 앨범 편집과 출력 파일 생성 |
| 실물 제작 | 실물 앨범 제작 공정 · 배송 |
| 결제 | 결제와 환불 · 스튜디오 정산 |
| 운영 | 관리자 운영 도구 (→ 백오피스 프로젝트로 별도 계획) |
| 운영 | 분석 및 성과 대시보드 |
| **AI 경계** | AI 컨셉 카테고리 생성과 정상 사진의 임의 폐기 |
| **AI 경계** | AI 취향 질문과 사용자별 개인화 학습 |
| **AI 경계** | AI 초안의 무작위 재생성이나 자동 제출 |
| 확장 | 전문 셀렉터 연결 또는 셀렉 대행 마켓플레이스 |

{: .decision }
"AI 경계" 세 줄은 단순한 범위 제외가 아니라 제품 정체성이다. 이 경계를 정한 과정은 [피벗 — 카테고리에서 유사도로](../background/pivot.md)에 있다.

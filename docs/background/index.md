# 배경

EasySelect는 "웨딩 사진 셀렉을 쉽게"라는 한 문장에서 출발했다. 이 섹션은 그 문장 뒤에 있는 두 개의 이야기다.

하나는 **문제**다. 촬영이 끝난 뒤 부부에게 도착하는 것은 완성된 앨범이 아니라 수천 장의 원본이고, 거기서부터 아무도 도와주지 않는 선택의 밤이 시작된다. → [문제 정의 — 셀렉 피로와 갈등](problem.md)

다른 하나는 **방향 전환**이다. 처음 설계는 "AI가 사진을 컨셉별로 분류해준다"였지만, 개발 초기에 이 방향을 버리고 유사도 기반으로 다시 설계했다. 이 결정이 이후 제품 전체의 AI 원칙이 됐다. → [피벗 — 카테고리에서 유사도로](pivot.md)

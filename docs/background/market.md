# 사업 전략

EasySelect의 수익 구조와 예상 위험을 정리했다.

## 수익 모델

[기획 피벗](business-pivot.md)에 따라 부부에게 직접 과금하지 않고, **사진 업체를 경유해 비용을 청구하는 B2B2C 구조**를 우선으로 삼는다.

- **B2B 구독** — 사진작가·업체가 플랫폼을 사용하고, 부부 1쌍당 수수료·추가금이 업체를 통해 청구
- **부가 서비스** — 모바일 청첩장, 보정 요청 중개 수수료

사업화 단계는 **베타 운영 + 촬영 업체 2~3곳 파일럿 → B2C 확대 · B2B 유료 전환**이다.

---

## 예상 위험과 대응

| 영역 | 위험 | 대응 |
|:---|:---|:---|
| 개발 | 10,000장 업로드·처리 시 서버 과부하 | Presigned URL 클라이언트 직접 업로드로 앱 서버 부하 분리. Lambda 비동기 파이프라인으로 업로드와 AI 분석을 분리 |
| 개발 | DINOv2 임베딩 기반 유사도 정확도 한계 | 임계값 벤치마크 튜닝. 슬라이더로 사용자가 스택 강도를 직접 조절하므로 오류가 신뢰 문제로 번지지 않는다 |
| 관리 | 3인 팀 역할 분산 병목 | 기능 단위 스프린트, 주간 싱크 미팅으로 병목 조기 식별 |
| 상용화 | 촬영 업체의 플랫폼 도입 저항 | 초기 무료 플랜 + B2B2C 채널 홍보 |
| 상용화 | 초기 사용자 확보 어려움 | 웨딩 커뮤니티·인스타그램 타겟 광고 + 촬영 업체 경유 간접 유입 |
| 비용 | AWS S3 비용이 용량·건수에 비례해 급증 | 저장 용량 티어 설계 + 보관 기간 경과 사진 S3 Glacier 아카이빙 |
| 법률 | 이미지 임베딩 데이터의 개인정보보호법 저촉 가능성 | 개인정보처리방침 내 처리 항목 명시. 임베딩은 분석 완료 후 파기 |

# 스튜디오 중심 워크플로

스튜디오가 사진을 준비하고 고객이 링크로 참여하면 원본을 다시 업로드하는 대기를 줄일 수 있다. 사용자를 전역 직무로 나누지 않고 현재 작업공간·갤러리 권한으로 업무를 나눈다.

## 업무 분담

- 스튜디오 구성원 : 사진 업로드·카테고리 운영·고객 초대·보정 결과 처리
- 고객 측 참여자 : 공동 셀렉·별점·보정 요청 작성
- 공유 참여자 : 공개된 컨셉 사진의 좋아요·댓글
- 최고 관리자 : 운영 변경·복원·감사·납품 기록

PERSONAL 작업공간에서는 직접 사진을 올리고 선택할 수 있다. 실제 권한표와 PERSONAL MEMBER의 구현 차이는 [제품 정책](../product/policies.md)과 [구현 기준](../implementation-status.md)에 기록한다.

---

## 인터뷰에서 확인한 문제

2026-08 스튜디오 인터뷰에서 보정 요청 커뮤니케이션과 업무 절감의 필요성을 확인했다. 이는 제품 방향의 근거이며 현재 기능 완료나 결제 의향 전체를 보장하는 지표는 아니다.

- 추상적인 보정 요청은 재수정으로 이어지므로 사진별 요청·주석과 회차 관리가 필요하다.
- 촬영 업체가 도입하려면 전달·요청 관리에 쓰는 시간이 줄어야 한다.
- AI는 1차 정리와 후보 제안에 사용하고 최종 선택은 사람이 한다.
- 원본 보정은 기존 편집 도구에서 수행하고 이 서비스는 요청과 결과 전달을 관리한다.

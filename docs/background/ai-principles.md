# AI 분류와 선택 원칙

AI는 탐색할 구조와 선택 후보를 제안하고 최종 판단은 사람이 한다.

## 편집 가능한 카테고리

사진을 `컨셉 → 세부 → 사진 배정`으로 정리한다. 서버는 외부 분석 결과를 카테고리로 만들고 사용자가 배정을 옮기거나 미분류 사진을 확인할 수 있게 한다. 작업 전체 성공 여부와 사진별 실패를 구분한다.

---

## 공동 셀렉과 추천

갤러리당 공동 셀렉과 사진별 별점을 저장한다. AI 추천은 기존 선택을 보존하고 후보를 제안한다. 결과를 자동 제출하거나 최종 판단을 대신하지 않는다.

---

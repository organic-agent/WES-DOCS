## 읽는 법

공개 영역에서 시작해 **역할별 레인**으로 갈라지고, 각 레인 안에서 위→아래가 여정의 순서입니다. **노드에 마우스를 올리면 그 화면과 직접 이어지는 앞뒤 단계만 남습니다** — 여정의 어느 지점에 있는지 따라가며 읽기 좋습니다.

- **공개 영역** — 랜딩 → OAuth 로그인 → 역할 분기. 어디서 가입했는지(랜딩 vs 초대 링크)가 역할을 정합니다. `역할 분기`에 올려 보면 세 갈래가 한눈에 보입니다.
- **사진작가 레인** — 온보딩 → 갤러리 운영(생성·업로드·초대·대시보드) → 앨범 템플릿 → 결과·보정 확인의 4개 묶음.
- **시스템·상태 레인** — 사람의 화면이 아닌 시스템의 일: 업로드 → 분석 상태 체인, 갤러리 공개 상태 축, 보정 요청 AI 전처리. `사진 업로드`에 올리면 업로드가 시스템 체인으로 넘어가는 지점이 보입니다.
- **부부 레인** — 탐색·정리(스택→폴더 고정) → 셀렉(직접·AI) → 협업 → 앨범 목업 → 제출·보정의 5개 묶음. `선택 앨범`에 올리면 셀렉의 모든 갈래가 이 화면에서 시작한다는 것이 드러납니다.
- **게스트 레인** — 토큰 입력 → 닉네임 → 열람 → 좋아요·댓글. 진입점이 로그인이 아니라 `협업 만들기 · 링크 발급`(부부 레인)이라는 점이 이 레인의 핵심입니다.

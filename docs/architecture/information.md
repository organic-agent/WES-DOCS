## 읽는 법

다이어그램은 공개 영역에서 시작해 **역할별 레인**으로 갈라집니다.

- **공개 영역** — 랜딩 페이지 → 카카오·구글·네이버 OAuth 로그인 → 역할 분기. 어디서 가입했는지(랜딩 vs 초대 링크)가 역할을 정합니다.
- **사진작가 레인** — 스튜디오 만들기 → 갤러리 목록(생성·진행·완료·보관) → 갤러리 생성과 온보딩 → 사진 업로드 → 부부 초대 → 셀렉 현황 대시보드 → 최종 결과·목업 확인. 앨범 템플릿 편집(규격·표지·2D 펼침면·프레임 레이아웃) 갈래가 따로 있습니다.
- **업로드 상태 체인** — 업로드 처리 중 → 성공(AI 분석 대기열 등록)/실패(자동 재시도 → 최종 실패 알림) → AI 시각적 유사도 분석 → RAW·HEIC 표시 변환. 상세 정책은 [사용자 흐름](../product/flows.md)의 상태 체인과 같습니다.
- **부부 레인** — 사진 탐색(그리드·라이트박스·비교 셀렉) → 5틱 유사도 슬라이더 → 유사 사진 스택 → **스택을 폴더로 고정** → 직접 셀렉 → 선택 앨범(현재/목표 장수) → AI 1차 셀렉 요청·검토 → 최종 제출/조기 마감 → 읽기 전용 재열람. 앨범 목업(순서·크롭 수정)과 협업 셀렉(링크 발급·집계·폐기) 갈래가 이어집니다.
- **게스트 레인** — 접속 토큰 입력 → 닉네임 설정 → 허용된 사진 열람 → 사진별 좋아요·댓글.
- **보정 갈래** — 작가의 보정 방식 등록 → 부부 요청 입력 → AI 전처리 → 동의 → 작가 수신.

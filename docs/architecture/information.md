# Information — 사용자 여정

갤러리에서 업로드·폴더 정리·셀렉·보정 작성을 이어 간다. 개인 사용자는 직접 개설하고, 스튜디오 고객은 초대로 참여한다.

## 역할과 완료

| 주체 | 주요 책임 |
|:---|:---|
| 개인 사용자·파트너 | 이용권·개설, 사진 정리, 공동 선택·공유, 요청서 전달·결과 확인 |
| 작가·스튜디오 | 사진 업로드·정리, 고객 초대, 제출·요청 확인, 보정 결과 처리 |
| 초대 고객 | 선택·별점·보정 작성, 게스트 반응 참고 |
| 게스트 | 공유된 사진 확인과 좋아요·댓글 |
| 관리자 | 별도 내부 화면에서 계정·쿠폰·데이터·처리 실패 운영 |

개인 갤러리는 단계 메뉴로 이전 작업을 다시 열 수 있다. 내보내기 취소는 보정본이 오기 전 조건부로 제공한다. 스튜디오의 제출 철회와 동일한 권한으로 설명하지 않는다.

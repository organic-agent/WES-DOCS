# 아키텍처

WES의 아키텍처는 **4단계 줌 레벨**로 그렸습니다. 같은 제품을 사용자 여정에서 AWS 물리 배포까지 점점 확대해 들어가는 구조라, 위에서부터 순서대로 읽으면 자연스럽습니다.

| 줌 | 다이어그램 | 답하는 질문 |
|:---|:---|:---|
| 1 | [Information — 사용자 여정](information.md) | 사용자는 어떤 화면을 어떤 순서로 만나는가 |
| 2 | [Application — 화면과 기능](application.md) | 그 여정을 어떤 UI·모듈·정책이 책임지는가 |
| 3 | [System — 시스템 구성](system.md) | 논리 서비스가 어떤 실행 인프라 위에서 결합되는가 |
| 4 | [Infrastructure — AWS 토폴로지](infrastructure.md) | 실제로 무엇이 어디에 배포되어 있는가 |

{: .note }
**4장 모두 인터랙티브 다이어그램**입니다 — 노드에 마우스를 올리면 연결된 요소만 강조되고, 클릭하면 고정됩니다. draw.io 원본(1~3번은 `WES-PM`, 4번은 `WES-Infra` 저장소)을 데이터로 재구성해 옮겼고, 원본 PNG 링크는 각 페이지 하단에 있습니다.

다이어그램 4종은 개발 시작 전 주(Cycle 0)에 만든 첫 산출물입니다 — Linear의 "00. 아키텍처" 프로젝트(2026-07-18 ~ 07-21)로 진행했고, 이후 기획이 바뀔 때마다 함께 갱신하고 있습니다. 8월 4일의 [카테고리→유사도 피벗](../background/pivot.md) 때는 4장 전부가 다시 그려졌습니다.

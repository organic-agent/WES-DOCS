# ADR-003 — 카테고리 분류를 버리고 유사도 스택으로

| | |
|:---|:---|
| 상태 | 채택 |
| 시기 | 2026-08-04 (기획 피벗) |

## 맥락

초기 설계에서 AI의 역할은 사진을 컨셉별 카테고리("야외", "드레스" 등)로 자동 분류하는 것이었다. 카테고리 분류에는 정답이 필요하고, 잘못 분류된 사진 하나가 기능 전체의 신뢰를 깎는다. 분류 체계를 부르는 이름부터 스튜디오·고객마다 다르다.

## 결정

AI는 컨셉 카테고리를 **만들지 않는다.** 시각적 유사도만 계산하고, 사용자가 5틱 슬라이더로 유사 사진 스택의 강도를 조절한다. 스택을 폴더로 **고정하는 주체는 사용자**다. 함께 확정한 경계 : 정상 사진을 버리지 않고, 취향을 학습하지 않고, 초안을 자동 확정·제출하지 않는다.

## 근거

유사도에는 정답이 없어도 유용성이 있다 — "비슷한 사진이 몇 장 묶여 있다"는 정보만으로 후보가 줄고, 묶음이 마음에 안 들면 슬라이더를 옮기면 된다. 판단이 사용자에게 남는 구조이므로 AI의 오류가 신뢰 문제로 번지지 않는다.

## 결과

- 기획서·아키텍처 다이어그램 4종을 함께 갱신했고(WES-PM 커밋 `b3d06f1`), 카테고리 필터 관련 Linear 이슈들은 Canceled 처리했다.
- 분류 모델 대신 **자기지도 임베딩(DINOv2) + 유사도 클러스터링**([ADR-004](adr-004-pgvector-union-find.md)) 경로가 열렸다. → 라벨 데이터가 필요 없으므로 콜드스타트 문제가 사라졌다.
- "AI가 하지 않는 것" 목록을 제품 원칙으로 기획서 §12에 명문화했다.

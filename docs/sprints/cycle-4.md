# Cycle 4 — FE 실연동 대전환

| | |
|:---|:---|
| 기간 | 2026-08-17 (월) - 08-23 (일) |
| 완료 / 스코프 | **63 / 68 (93%)** — 10건으로 시작해 68건으로 종료 |
| 라벨 분포 (완료분) | FE 58 · BE 3 · 공통 2 |

## 목표

프로토타입의 localStorage 목업을 걷어내고 **작가 여정 전체를 실서버 연동으로 전환한다** — 로그인부터 업로드, AI 자동 분류, 앨범 관리까지.

## 완료한 일 (기능 흐름 순)

### 인증·초대 실연동
OAuth 로그인 플로우(콜백 라우트·소셜 버튼), 리다이렉트 성공·실패 처리, 초대 링크 랜딩 `/invite/[token]`과 수락 흐름, 로그인 과정의 inviteToken 보존, 약관·개인정보 페이지 (WES-8, 10, 79, 83, 84, 163, 199, 200)

### 스튜디오·온보딩 실연동
스튜디오 생성 폼·슬러그 실시간 검증(디바운스·중복검사 API), Mock 갤러리 생성 온보딩 — 생성 API 연동·redirect·재시도 UI (WES-16 - 18, 116 - 121, 204, 205)

### 갤러리 관리 실연동
목록·생성·삭제 API 전환(목업 저장소 제거), 상세 서버 전환, 상태 전환(열기/마감/재오픈)·확인 다이얼로그, 초대 링크 발급·폐기·멤버 현황 (WES-122 - 127, 25, 206, 208 - 210, 212 - 214)

### 업로드 파이프라인 실연동
3단계 파이프라인(presigned 발급 → S3 직접 PUT → 완료 통지) 클라이언트, 드래그앤드롭·파일 검증, 파일별 진행률·실패·재시도, 업로드 후 처리 상태 폴링, 임베딩 실행 트리거, 실사진 그리드 전환(viewUrl·미리보기 준비 상태·URL 만료 재조회) (WES-32 - 34, 130 - 135, 217 - 224)

### AI 자동 분류·앨범 실연동
클러스터 조회 + 유사성 레벨 슬라이더 통합, 묶음 미리보기 실데이터, 클러스터 고정 → 앨범 만들기, 앨범 목록·조회·관리(이름 변경·삭제·사진 담기/이동/제거) (WES-225 - 231, 241)

### BE — 부부·게스트 화면 준비
갤러리 사진 목록 API(필터+페이지네이션), 공유 링크 생성 API(토큰·만료), 익명 게스트 세션 발급 (WES-55, 69, 70)

### 공통
클러스터링 성능 개선, 리팩토링과 컨벤션 정리 (WES-193, 194)

## 하이라이트

- **한 주에 63건.** 사이클을 10건으로 시작해 구현 중 발견한 작업을 계속 이슈로 쪼개 넣으며 68건으로 마감했다. "화면은 있는데 데이터가 가짜"였던 서비스가 이 주를 지나며 실제로 동작하는 서비스가 됐다.
- 작가 여정(가입 → 스튜디오 → 갤러리 → 업로드 → AI 분류 → 앨범)이 끝에서 끝까지 실서버로 이어졌다.
- 버그 픽스는 업로드 URL 발급 400(fileName 필드 누락, WES-224) 하나뿐이다 — 실연동 규모 대비 조용한 한 주였다.

## 현재 제품으로 이어진 작업

- OAuth 콜백·초대 수락과 온보딩을 실제 API로 연결했다.
- 갤러리 목록·생성·삭제와 열기·마감·재오픈을 연결했다.
- 업로드 URL 발급·직접 PUT·완료 통지, 진행률·실패 재시도를 구현했다.
- 실사진 그리드의 파생본·준비 상태·URL 만료 재조회를 연결했다.

당시 날짜·집계를 유지하고 현재 제품과 관련된 작업만 정리한다. 이 기록은 오늘의 Web 연동 완료를 뜻하지 않는다. 이후 서버·관리자 변경은 [Cycle 6](cycle-6.md), 현재 소스·배포 상태는 [구현 기준](../implementation-status.md)을 따른다.

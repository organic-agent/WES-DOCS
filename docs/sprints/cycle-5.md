### AI — photoselect 모듈 착수
**"photoselect 모듈 — AI 1차 셀렉"** 프로젝트를 시작했다. 웨딩 사진 AI 1차 셀렉을 위한 점수 파이프라인(배치) + 추천 채우기 + 사진 진단이고, LLM은 소규모 호출만 쓰고 **최종 결정은 사람**에게 남긴다.

| 마일스톤 | 내용 |
|:---|:---|
| M1 기반 | **모델 스파이크 — 후보 모델 골든셋 평가와 채택 확정 (WES-232, 진행 중)**, embedder 패턴 스캐폴드 |
| M2 코어 | 점수 파이프라인(배치 A) · 추천 채우기(배치 B) · LLM 근거 문장화 · 골든셋 평가 리그레션 |
| M3 제공 | 사진 진단 동기 API · Terraform 배포 (ECR·Lambda·IAM·CloudWatch) |

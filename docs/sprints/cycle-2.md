## 목표

세 갈래를 동시에 진행한다 — 디자인 시스템과 부부 화면(FE), 프로덕션 환경 완성(INFRA), 사진 임베딩 파이프라인의 첫 연결(AI/BE).

## 완료한 일

### FE — 디자인 시스템과 화면
- 디자인 시스템 구축 : 컬러 팔레트·타이포그래피 정의, 공통 컴포넌트, 스타일 가이드 문서화, 디자인 토큰 코드 반영 (WES-166 - 169, 185)
- 부부 페이지 디자인 → 레이아웃 → 시안 → 리뷰·확정 (WES-174 - 177)
- 랜딩 페이지 코드 구현, 소셜 로그인 버튼 (WES-186, 78)

### INFRA — 프로덕션 완성
- VPC·서브넷·보안 그룹 network 모듈, 원격 State 부트스트랩 (WES-109, 108)
- ALB · Route 53 · ACM HTTPS 라우팅과 OAuth 콜백 URL 확정 (WES-112)
- 인증 백엔드 프로덕션 배포 기반 완성 — EC2 + RDS (WES-107)
- [ImageLoad PoC] 사진 뷰어 로딩 속도 측정 마무리 (WES-165)

### BE — 스튜디오 도메인
- 스튜디오 도메인 CRUD, URL 슬러그 중복 검사 API (WES-19, 20)
- 갤러리·이미지·스튜디오 DB 테이블 생성 (WES-180)

### AI — 임베딩 파이프라인 첫 연결
- S3 이미지 임베딩 결과 벡터 DB(pgvector) 저장 로직 (WES-189)
- 유사도 기반 클러스터링 메타데이터 조회 API (WES-190)

## 하이라이트

- `easyselect.kr`이 HTTPS로 열렸다 — ALB·ACM·Route 53이 연결되고 OAuth 콜백 URL까지 확정되어, 로컬이 아닌 실제 도메인에서 로그인이 돌기 시작했다.
- 임베딩 → pgvector → 클러스터 조회의 뼈대가 이 주에 처음 이어졌다. 이후 모든 AI 기능이 이 위에 쌓인다. → [AI 파이프라인](../tech/ai-pipeline.md)
- ImageLoad PoC가 결론(파생본 전환 + 선로드 + 프리페치)에 도달했다. → [ADR-002](../decisions/adr-002-preview-derivatives.md)
